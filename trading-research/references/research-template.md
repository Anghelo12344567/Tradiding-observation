# Plantilla de informe de investigación

Rellena todas las secciones. Si una no tiene datos, escribe «Sin dato» y por qué. Cada hecho lleva `[fuente, fecha]`.

```
# [Activo / tema] — informe de investigación
Fecha de consulta: AAAA-MM-DD · Horizonte del usuario: [..] · Decisión que informa: [..]

## 1. Contexto en tres líneas
[Qué es, qué lo mueve. Solo hechos con fuente.]

## 2. Hechos recientes
- [Hecho] [fuente, fecha]
- ...

## 3. Calendario de eventos próximos
| Fecha | Evento | Por qué importa |
|---|---|---|

## 4. Escenarios (no son predicciones)
| Escenario | Condición que lo activa | Qué lo invalidaría |
|---|---|---|
| Alcista | | |
| Bajista | | |
| Lateral | | |

## 5. Riesgos conocidos
[Liquidez, regulación, concentración, eventos binarios, apalancamiento…]

## 6. Qué no sé
[Datos que faltan, fuentes que se contradicen, lo que habría que verificar]

## 7. Fuentes
1. [título, emisor, fecha, enlace]

No es consejo financiero.
```

## Criterios de calidad de las fuentes
- Primaria (comunicados del emisor, regulador, banco central, estados financieros) > agencia de noticias > análisis de terceros > redes sociales.
- Un dato de una sola fuente no verificable se marca «una fuente».
- Descarta cifras sin fecha; los datos de mercado envejecen en minutos.
- Si el usuario pega datos suyos, trátalos como fuente y cítalos como «aportado por el usuario».
